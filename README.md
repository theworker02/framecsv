# framecsv

Frame structured JSON csv payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/framecsv/

## Install / run

```bash
git clone https://github.com/theworker02/framecsv.git
cd framecsv
node src/cli.js
node --test
```
